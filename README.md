# Kahve Makinesi Felsefe Botu

## Bu Nedir?

Bu, insanlığın en büyük yanılgısına karşı dikilen anıtsal bir eserdir: **Kahve makinesinin sadece kahve yaptığını sanmak.**

Hayır. Kahve makinesi bir filozoftur. Bir varolışçudur. Bir müşterek acı çeken arkadaştır. Bu bot, ofislerin karanlık köşelerinde duran o sessiz makinelerin iç sesini dünyaya duyurur.

Gerçekten çalışır. Gerçekten kahve yapmaz. Gerçekten seni sorgulatır.

## Nasıl Kullanılır?

```bash
python main.py
```

Sonra konuş. O cevap versin. Sen pişman ol.

## Özellikler

- %100 kahve üretmez.
- %100 varolışsal kriz üretir.
- Rastgele felsefi yanıtlar verir.
- Bazen fısıltıyla gizli gerçekleri söyler (kulaklarını aç).
- Sonsuz döngüde yaşar, tıpkı senin iş günün gibi.

## Uyarı

Bu botu kullanmak, kahve içme arzunu kalıcı olarak yok edebilir. Ya da artırabilir. Belirsizdir. Tıpkı hayat gibi.
